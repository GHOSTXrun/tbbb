What happens
  1. 1 · Validate. Fields are checked here and again on the server.
  2. 2 · Pin. Image + metadata JSON are pinned to IPFS.
  3. 3 · Build & simulate. The pump.fun create transaction is built with pump.fun's official SDK and simulated before you see a signing prompt.
  4. 4 · Sign. Your wallet signs; KYVEXA never holds your keys or the mint authority.
  5. 5 · Register. A second transaction creates the mint's Privacy Rings SPL interface.
Why two transactions?
Privacy Rings registration creates the mint's registry entry and vault, which needs the mint to exist. pump.fun's create transaction is already near Solana's size and compute limits, so KYVEXA does not bundle them atomically — registration runs right after, with its own status. If it fails, the token is still live and you can register from its dashboard.
